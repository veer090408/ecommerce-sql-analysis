# E-Commerce Data & Revenue Analytics

E-commerce transaction data analisys project using SQL and Python (Pandas).
Dataset: "Brazilian E-Commerce Public Dataset by Olist" [Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).

Top Product Categories: Identificating top 5 product category with highest revenue 5.
Monthly Revenue Trend: Analyzing monthly transaction trend  to observe sales growth patterns.

Database: SQLite
Language & Libraries: Python, Pandas
